## Description

I was part of Jumbyte, a team of 19 people from Tufts University participating in the MITRE Embedded Capture the Flag Competition. We designed and developed a secure satellite TV system using multi-layer cryptography via WolfSSL and subscription authorization with key management. 

## Architecture Overview
The Uplink sends encoded data of TV frames to the satellite, which then sends the frame to the receiver, where viewers “watch TV”. The receiver also consists of the decoder, which checks the validity of TV frames and decodes encryptions for actively subscribed channels. 

![architectureoverview]({{ "/assets/images/architecture.jpg" | relative_url }})

## Key Security Features
- Encryption 
We utilized two layers of AES symmetric encryption to secure our satellite.

- Authentication 
Our authentication process ensures that tampered messages are rejected by the decoder, utilizing SHA-256 for hashing and HMAC SHA-256 to ensure message integrity.

- Forward Secrecy 
Ephemeral session keys for each channel are utilized to ensure forward secrecy.

- Replay Prevention 
Monotonically increasing timestamps prevent unauthorized viewers from replaying
frames to which they should not have access.

- Secure Authorization and Access Control 
Subscription-based access control prevents unauthorized users from viewing channels they are not subscribed to.

- Memory Safety and Buffer Overflow 
We enforce memory safety through the use of MPU (Memory Protection Unit) guard regions to prevent buffer overflows and unauthorized memory access. Additionally, all buffer operations include explicit bound checking to mitigate memory corruption vulnerabilities. UART input is validated to prevent buffer overflows, and our system follows secure memory allocation practices to prevent stack and heap overflows.

## Software-Side Encryption & Decryption Security
Considering software-side security, we first imagined possible attacks such as expired subscription, replay attacks, pirated subscription, no subscription, tampering of frames, key collision attack, and brute force attacks. We then designed mitigation strategies balancing security and feasibility.
