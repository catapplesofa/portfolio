## Description

The satellite TV system employs a defense-in-depth security architecture that protects against multiple attack vectors commonly found in broadcast systems. Rather than relying on a single security mechanism, the implementation uses layered protection to ensure content integrity, viewer authentication, and system resilience.

## Key Security Features
Multi-Layer Encryption: The system implements dual AES symmetric encryption layers to protect satellite transmissions from interception and unauthorized access.

Message Integrity & Authentication: SHA-256 hashing combined with HMAC SHA-256 ensures that any tampering with transmitted messages is immediately detected and rejected by the decoder.

Forward Secrecy Protection: Ephemeral session keys are generated for each channel, ensuring that even if current keys are compromised, previously transmitted content remains secure.

Anti-Replay Security: Monotonically increasing timestamps prevent malicious actors from capturing and replaying frames to gain unauthorized access to content.

Subscription-Based Access Control: A robust authorization system ensures only properly subscribed users can access specific channels, preventing unauthorized viewing.

Memory Protection: The system implements comprehensive memory safety through Hardware Memory Protection Unit (MPU) guard regions, explicit buffer bound checking, input validation for UART communications, and secure memory allocation practices to prevent buffer overflows and memory corruption attacks.
Technical Implementation

The project leverages WolfSSL for hardware-optimized cryptographic operations, ensuring both security and performance efficiency suitable for real-time satellite broadcasting requirements. The design balances the need for robust security with the performance constraints typical of embedded satellite communication systems.

This implementation serves as a model for secure broadcast systems, demonstrating how multiple security principles can be integrated into a cohesive, production-ready satellite TV infrastructure.
